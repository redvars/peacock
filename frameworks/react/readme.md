# @redvars/peacock-react

React components for [Peacock](https://peacock.redvars.com), generated from its custom elements manifest. Works with React 18 and 19.

```bash
npm install @redvars/peacock @redvars/peacock-react
```

```tsx
import { useState } from 'react';
import '@redvars/peacock/styles.css';
import { Button, Select } from '@redvars/peacock-react';

export function Example() {
  const [choice, setChoice] = useState('alpha');
  return (
    <>
      <Select
        label="Choice"
        options={[{ label: 'Alpha', value: 'alpha' }, { label: 'Beta', value: 'beta' }]}
        value={choice}
        onChange={event => setChoice(event.detail.value)}
      />
      <Button onClick={() => console.log(choice)}>Save</Button>
    </>
  );
}
```

- **Names:** `wc-date-picker` is `DatePicker`. Each component also exports `DatePickerElement` (the element type, for refs) and `DatePickerProps`.
- **Props** are set as element properties, so arrays, objects and booleans arrive as they are.
- **Events:** every Peacock event has an `onX` prop with its typed `detail` (`change` → `onChange`, `menu-item-activate` → `onMenuItemActivate`). This works on React 18 too, without refs.
- **Registration:** importing a component defines its element and the Peacock elements it renders. You don't need `loader.js`, and unused components are tree-shaken.
- **Server rendering:** the package is `'use client'`. Render Peacock components on the client only, for example through `next/dynamic` with `ssr: false`.

Full guide: [peacock.redvars.com/frameworks/react](https://peacock.redvars.com/frameworks/react/).

## Development

`src/generated/` is generated by `components/bin/framework-gen.mjs`; don't edit it. `npm run build` regenerates it from `../../components/dist/custom-elements.json` (build `components` first) and compiles to `dist/`. `npm run demo` starts the demo in `demo/`.
